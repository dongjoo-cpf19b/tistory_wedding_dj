# 웨딩 시안 만들기

스튜디오 씬과 신랑·신부 얼굴, 헤어·드레스 참고사진을 모아 촬영 시안을 준비하는 무료 공개 도구입니다.

**공개 초기 버전 v0.1.0** · HTML/CSS/JavaScript + 선택형 Python 로컬 서버 · MIT License

## 주요 기능

- 신랑·신부 얼굴사진 공통 등록
- 최대 12개 촬영 씬, 씬별 스튜디오·드레스·헤어 참고사진 등록
- 분위기, 포즈, 화면 비율, 의상, 헤어 및 촬영 메모 입력
- 참고사진의 역할을 구분한 AI 요청문 복사 및 참고사진 모음 JPG 저장
- AI에서 생성한 이미지 불러오기, 결과 이미지 저장
- 사진과 메모를 포함한 프로젝트 파일 저장·불러오기
- 전체 씬 인쇄 및 브라우저의 PDF 저장 기능 이용
- 선택 기능: 개인 API 키를 연결한 로컬 실행에서 OpenAI 이미지 생성

## 바로 시작

### 별도 설치 없이 이용

1. GitHub의 **Code → Download ZIP**으로 소스 코드를 내려받습니다.
2. 압축을 풀고 `index.html`을 웹브라우저로 엽니다.
3. 신랑·신부 얼굴사진과 스튜디오 씬을 등록합니다.
4. 원하는 의상·헤어·구도를 입력합니다.
5. **AI 요청문 복사**, **참고사진 모음 저장**을 누릅니다.
6. 본인이 이용하는 이미지 생성 AI에 요청문과 참고사진 모음을 함께 첨부합니다.
7. 결과 이미지를 내려받아 **생성 결과 이미지 추가**로 넣습니다.
8. **프로젝트 저장**으로 작업을 보관하고, **시안 인쇄 / PDF**로 촬영용 자료를 만듭니다.

이 방식은 AI 계정에 자동 로그인하거나 구독 서비스를 대신 호출하지 않습니다. 사용하는 AI의 이미지 생성 지원 여부와 이용 조건에 따릅니다. 파일로 직접 실행할 때 복사 권한이 제한되면 선택된 요청문을 직접 복사하세요.

### 로컬 실행과 선택형 API 생성

Python 3.10 이상이 있으면 추가 패키지 설치 없이 실행할 수 있습니다.

```sh
python server.py
```

Windows에서는 `start-windows.bat`를 실행해도 됩니다. 터미널에 표시된 `http://127.0.0.1:8765`를 브라우저에서 엽니다.

API 생성이 필요하면 실행 전에 본인의 `OPENAI_API_KEY` 환경변수를 설정합니다. 키를 채팅, GitHub, 프로젝트 파일에 넣지 마세요. 아래 `YOUR_OWN_KEY`는 설명용 자리표시자입니다.

```powershell
# Windows PowerShell
$env:OPENAI_API_KEY = "YOUR_OWN_KEY"
python server.py
```

```sh
# macOS / Linux
export OPENAI_API_KEY="YOUR_OWN_KEY"
python3 server.py
```

앱의 **앱에서 바로 생성하기**를 펼쳐 사진 전송·비용 안내를 확인한 뒤 생성합니다. 신랑·신부 얼굴 2장과 스튜디오 씬 1장은 필수입니다. 한 번에 이미지 1장을 요청하며 자동 재시도하지 않습니다.

기본 모델은 `gpt-image-2.5-sunburst`, 품질은 `medium`입니다. 계정별 사용 가능 모델은 다를 수 있으며 `OPENAI_IMAGE_MODEL` 환경변수로 변경할 수 있습니다. 사용 모델이 Images Edit API의 JSON 이미지 입력과 지정된 해상도를 지원해야 합니다.

API 사용료는 사용자의 API 계정에 부과됩니다. 일반 ChatGPT 구독과 별도의 API 이용 조건을 확인하세요. 이 프로젝트 운영자에게 사용료가 지급되지 않습니다.

## 사진과 작업 보관

- 사진과 메모는 브라우저 메모리에만 유지되며 서버에 자동 저장하지 않습니다.
- 새로고침하거나 창을 닫기 전에 **프로젝트 저장**을 실행하세요.
- `.wedding.json` 파일에는 개인 사진과 메모가 포함됩니다. 본인 PC에 보관하고 공개 저장소에 올리지 마세요.
- 참고사진은 긴 변 1,600px 이하 JPG로 변환하며 이미지 메타데이터를 유지하지 않습니다.
- JPG·PNG·WebP, 입력 사진 한 장 20MB 이하를 지원합니다. 프로젝트 파일은 160MB 이하입니다.
- 기본 기능은 사진을 외부로 전송하지 않습니다. 선택형 API 생성 버튼을 누를 때 선택한 씬의 참고사진과 요청문을 OpenAI에 전송합니다.
- 로컬 서버는 `127.0.0.1`에만 연결하고 정적 앱 파일만 제공합니다. API 키는 환경변수에서 읽으며 브라우저로 반환하지 않습니다.
- 서버의 외부 공개 배포나 공동 사용을 전제로 만든 버전은 아닙니다.

## 결과물 이용

AI 결과는 촬영 구도·의상·헤어를 협의하기 위한 참고 시안입니다. 얼굴 재현도와 배경·의상 일치 정도는 모델 및 입력사진에 따라 달라지며 실제 촬영 결과를 보장하지 않습니다. 본인 또는 사용 동의를 받은 인물사진, 이용 가능한 스튜디오·의상 사진을 사용하세요.

## 검증 범위

브라우저 기본 기능과 프로젝트 입력 검증, 로컬 서버의 요청 검증·동시 생성 제한·오류 처리를 확인합니다. 자동 테스트는 외부 API를 모의 응답으로 대체하며 비용이 발생하지 않습니다. 실제 유료 API 생성 품질과 계정별 모델 접근 권한은 사용자의 환경에서 별도로 확인해야 합니다.

```sh
node --test tests/core.test.cjs
python -m unittest discover -s tests -v
```
