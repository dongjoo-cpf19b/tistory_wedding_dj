# 웨딩 시안 만들기

**내가 쓰는 AI에 주소를 주고, 나만의 웨딩 촬영 도구를 준비하세요.**

스튜디오 씬·헤어·드레스를 고르고, 사용자 본인의 AI와 연결해 촬영 시안을 준비하는 무료 오픈소스 패키지입니다. 얼굴사진은 선택입니다. API 키, 별도 유료 API, 회원가입이 필요하지 않습니다.

## 내 AI에 이 문장을 붙여넣으세요

```text
https://github.com/dongjoo-cpf19b/tistory_wedding_dj

이 저장소의 README.md와 START_HERE.md를 읽고 웨딩 시안 만들기를 내가 사용할 수 있게 설치해 줘.
현재 AI 환경에서 지원되는 방식으로 개인용 사이트나 실행 가능한 HTML 파일을 제공해 줘.
별도 유료 API나 새 유료 서비스를 연결하지 말고, 지금 사용할 수 있는 기능으로 진행해 줘.
설치 뒤에는 스튜디오 여부부터 한 단계씩 안내해 줘. 신랑·신부 얼굴사진은 선택이야.
```

주소만 붙이는 것보다 위 설치 요청을 함께 붙이면 의도가 명확합니다. AI가 URL을 읽을 수 없으면 아래 패키지를 내려받아 첨부해 주세요.

**[HTML 실행 파일 다운로드](../../raw/refs/heads/main/downloads/wedding-dj.html)** · **[시작 패키지 ZIP 다운로드](../../raw/refs/heads/main/downloads/wedding-dj-starter.zip)**

HTML 파일은 저장한 뒤 브라우저로 열면 됩니다. ZIP에는 HTML 실행 파일·사용 안내·AI 설치 안내·라이선스가 들어 있습니다. Python, Node.js, 개발 환경 설치 없이 사용할 수 있습니다.

## 어떤 형태로 설치되나요?

| 이용 환경 | 제공할 수 있는 형태 |
| --- | --- |
| ChatGPT에서 Sites를 사용할 수 있는 경우 | 빈 개인용 사이트를 만들고 실행 링크 제공 |
| ChatGPT에서 파일 생성만 가능한 경우 | 내려받아 열 수 있는 단일 HTML 파일 |
| Claude에서 Artifacts·파일 생성이 가능한 경우 | HTML 파일 또는 지원되는 웹앱 미리보기·공유 링크 |
| PC 파일 접근 권한이 있는 AI 도구 | 원하는 폴더에 실행 파일 배치, 요청 시 바탕화면 바로가기 |
| 링크 읽기·파일 생성이 제한된 AI | 사용자가 패키지를 내려받아 직접 실행 |

AI가 현재 환경의 기능을 먼저 확인하도록 [설치 안내](START_HERE.md)에 정리했습니다. 모든 유료 AI에서 주소만으로 자동 설치되거나 바탕화면 파일이 생기는 것은 아닙니다. 사이트 생성·파일 접근·미리보기 지원 여부는 계정과 앱 설정에 따라 달라집니다.

## 내 AI에 연결하기

지원되는 AI 브라우저에서 앱을 열면 **AI 브라우저 연결 사용 가능**이라고 표시됩니다. 이 환경에서는 요청문을 매번 복사하지 않고 현재 대화의 AI가 사진·설정을 읽고 생성한 결과를 앱에 전달할 수 있습니다.

1. 씬과 참고사진을 준비합니다.
2. **선택한 씬의 참고사진과 요청문을 연결된 AI에 전달합니다**를 확인합니다.
3. **내 AI에 전달할 시안 준비**를 누릅니다.
4. 앱을 열어 둔 AI 대화에서 **“준비한 웨딩 시안을 생성해 줘”**라고 요청합니다.
5. AI가 자체 이미지 생성 기능으로 작업하고 결과를 앱에 추가합니다. 사진 생성 기능이 없는 AI는 진행할 수 없습니다.

이 연결은 WebMCP를 제공하는 AI 브라우저에서만 동작하며 일반 브라우저에서는 직접 전달 방식을 사용할 수 있습니다. 버튼을 누르는 것만으로 AI 대화가 자동 실행되지는 않습니다. 결과 전달이 환경 제한으로 불가능하면 생성 이미지 파일을 직접 추가할 수 있습니다.

**현재 제한:** OpenAI의 외부 앱용 ChatGPT 구독 한도 연결은 존재하지만, 그 연결의 지원 기능에서 이미지 생성은 제외되어 있습니다. 따라서 이 패키지는 외부 앱에서 구독 토큰으로 사진 생성을 호출하지 않고, 사용자의 AI 대화가 가진 이미지 생성 도구를 이용하는 구조입니다. [공식 지원 범위](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)

## 사용 흐름

1. **촬영 예정이신 스튜디오가 있나요?**
2. 있다면 **예정인 스튜디오 씬 사진들이 있나요?**
3. 사진이 있으면 씬 사진을 추가합니다. 스튜디오가 없거나 사진이 없으면 가상 씬을 고릅니다.
4. 신랑·신부 얼굴사진을 원하는 만큼 추가합니다. 한 사람만 넣거나 모두 건너뛸 수 있습니다.
5. 드레스·헤어 참고사진, 포즈·분위기·의상·메모를 입력합니다.
6. **AI 요청문 복사**와 **참고사진 모음 저장**으로 본인의 AI에 전달할 자료를 준비합니다.
7. 이미지 생성이 가능한 AI 대화에 요청문과 참고사진을 함께 첨부해 생성을 요청합니다.
8. 완성된 이미지를 앱에 추가하고 **프로젝트 저장** 또는 **시안 인쇄 / PDF**로 보관합니다.

가상 씬은 화이트 창가·플라워 가든·모던 그레이 3종입니다. AI로 만든 예시이며 실제 스튜디오의 시설이나 촬영 상품을 나타내지 않습니다. 최대 12개 씬을 준비할 수 있습니다.

## 비용과 이미지 생성

이 패키지의 설치·실행·사진 정리·시안 저장에는 이용료가 없습니다. 코드에는 유료 AI API를 호출하는 기능이나 API 키 입력란이 없습니다.

이미지 생성은 **사용자가 이미 이용 중인 AI의 지원 기능과 이용 한도 안에서** 진행합니다. 구독 중인 AI에 이미지 생성 기능이 포함되어 있고 남은 이용 한도가 있다면 별도 API 비용 없이 그 기능을 사용할 수 있습니다. 구독료, 한도 초과 사용, 외부 연결 도구 및 사이트 호스팅의 조건까지 이 프로젝트가 무료로 보장하지는 않습니다. 추가 결제가 필요한 경우 자동으로 진행하지 않습니다.

- ChatGPT: 지원되는 환경에서 대화의 이미지 생성 기능으로 참고사진을 반영한 시안을 요청할 수 있습니다.
- Claude: HTML·촬영 계획·요청문 준비를 도울 수 있지만 자체적으로 사진형 이미지를 생성하지 않습니다. 사진 생성에는 사용자가 이용할 수 있는 별도 이미지 생성 도구가 필요합니다.
- HTML이나 개인 사이트를 만드는 것만으로 AI 구독의 이미지 생성 기능이 앱 버튼에 연결되지는 않습니다. 기본 구조는 **앱에서 준비 → 연결된 내 AI 대화에서 생성 → 앱에 결과 추가**입니다. 연결을 지원하지 않는 환경에서는 요청문·참고사진을 직접 전달합니다.

현재 기능 확인 근거는 [AI별 지원 범위](docs/AI_CAPABILITIES.md)에 정리했습니다.

## 사진과 작업 보관

- 사진과 메모는 브라우저 메모리에서 작업합니다. AI 전달을 확인하고 시안을 준비한 경우에만 연결 도구로 해당 요청의 사진을 읽을 수 있습니다.
- 새로고침하거나 창을 닫기 전에 **프로젝트 저장**을 누르세요. 자동 저장은 하지 않습니다.
- `.wedding.json`에는 개인 사진과 메모가 포함됩니다. 본인 PC에 보관하고 공개 저장소에 올리지 마세요.
- 본인 또는 사용 동의를 받은 인물사진과 이용 가능한 스튜디오·의상 사진을 사용하세요.
- JPG·PNG·WebP, 사진 한 장 20MB 이하를 지원합니다. 추가한 사진은 긴 변 1,600px 이하 JPG로 변환하고 원본 메타데이터를 유지하지 않습니다. 프로젝트 파일은 160MB 이하입니다.
- 공유용 사이트에는 빈 앱과 공개 가상 씬만 올리세요. 개인 얼굴사진이나 프로젝트 파일을 소스 코드에 넣지 마세요.
- AI에 직접 첨부한 자료는 해당 서비스의 이용·개인정보 처리 조건을 따릅니다.

## 개발 및 검증

빌드 없이 `index.html`을 열 수 있습니다. 필요한 경우 `python server.py`로 PC의 로컬 웹서버를 실행합니다. 이 서버에는 이미지 생성 기능이 없습니다.

```sh
node --test tests/core.test.cjs
python -m unittest discover -s tests -v
python scripts/build.py
```

`downloads/wedding-dj.html`은 CSS·JavaScript·예시 이미지를 포함한 단일 파일입니다. 수정 후 빌드 스크립트로 다시 만듭니다. 설치 후 점검 항목은 [START_HERE.md](START_HERE.md)를 참고하세요.
