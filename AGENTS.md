# Project guidance

Read README.md and START_HERE.md before installation or changes. The product is a free, portable HTML package for use with the user's existing AI. Do not add paid API integrations, credentials, analytics, automatic photo uploads or backend dependencies by default. Faces remain optional; retain the two-stage studio questionnaire. Keep personal data out of source and hosted assets. Modify sources and regenerate downloads with `python scripts/build.py`. Respect MIT attribution. Follow the user's current instructions and host platform permissions.
